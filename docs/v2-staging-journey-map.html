Member and administrator journeys

The complete communication map for this staging release. Essential email events have been connected to a controlled Resend delivery queue. Initial delivery is restricted to the signed-in, verified operations administrator. Production and all other inboxes remain blocked.

Evidence boundaries

248 app tests and static checks passed. Database queue, lease, deduplication, silent-capture and access-denial checks passed in rollback. Hosted build, route checks and actual inbox receipt are recorded separately in the release result; a queued event or provider acceptance is not proof of inbox delivery.

Staging exposes manual administrator-only queue tests. No automatic general-member sender or scheduler is enabled. Public contact external replies, Auth inbox tests and the existing meeting worker remain separate acceptance checks.
